03
Academic security research / 2025

NAegisQ

Exploring transaction integrity and cryptographic evidence in a banking security framework.

Post-quantum cryptographyPostgreSQLForensic traceability
Explore the documentation ↗

My final-year project at ZCAS University examined how cryptographic signing, database records and blockchain anchoring can work together to support tamper detection.

  1. Sign transaction
  2. Store record
  3. Anchor & verify
Read the case study

The question

How can a transaction workflow combine post-quantum cryptography with evidence that helps reveal changes to stored records?

My contribution

I worked on the framework, set up the database and anchored transactions to an Ethereum-based environment. The documented design combines Kyber/ML-KEM and Dilithium/ML-DSA concepts with PostgreSQL and Merkle-root anchoring.

Evidence & scope

The public repository contains a README describing architecture and workflows. It currently does not include the implementation or reproducible test evidence. This is an academic project, with ISO 27037 and PCI-DSS referenced as design context rather than a certification claim.
