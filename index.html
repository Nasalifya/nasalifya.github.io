Parabellum: a dual-SIEM security operations lab

A segmented environment on enterprise hardware where I practise systems administration and follow a security event from an endpoint to a searchable dashboard. Everything below is documented in the public repository, with screenshots taken from the running lab.

How the pipeline fits together

  • Windows endpoints
  • Wazuh agent
  • Wazuh server
  • Universal Forwarder (TCP 9997)
  • Splunk index wazuh-alerts

Wazuh does real-time endpoint detection, file integrity monitoring and MITRE ATT&CK mapping. Splunk adds search, dashboards and longer retention. I verified the forwarder connection with splunk list forward-server.

A detection gap I closed

Wazuh did not flag the vsftpd backdoor exploit by default. I read the raw logs, found the pattern, wrote a custom rule and mapped it to MITRE ATT&CK T1190, then confirmed the alert end to end in Splunk.

<rule id="100001" level="12">
  <if_group>syslog</if_group>
  <match>vsftpd</match>
  <description>vsftpd backdoor exploitation attempt - MITRE T1190</description>
  <mitre><id>T1190</id></mitre>
</rule>

NAegisQ

Final-year project, ZCAS University, 2025
Academic security research
  • Post-quantum cryptography
  • Go
  • PostgreSQL
  • Forensic traceability

A banking security framework that asks how transactions can be signed with post-quantum algorithms and how stored records can be checked for tampering.

  1. Sign the transaction
  2. Store the record
  3. Anchor a Merkle root and verify

The documented design pairs ML-KEM-768 and ML-DSA-65 with a Go and PostgreSQL backend, and anchors Merkle roots to an Ethereum test network so altered records can be detected.
